# M1 test results

Recorded 2026-10-05 on the author's machine (Intel Core i7-13700H, Windows 11, Python 3.14.5).
CI re-runs the local suite on Ubuntu with Python 3.12, and runs two extra jobs: a Kafka round trip
against an `apache/kafka:4.3.1` broker, and the PyFlink 2.3 job on Java 17.

## Tests: 57 passed, 4 skipped locally, 0 failed

Command: `make test`. The four skipped tests need a Kafka broker or PyFlink, which the CI jobs
provide (`pytest -m kafka`, `pytest -m flink`).
